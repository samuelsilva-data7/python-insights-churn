# &#x20;Python Insights — Análise de Cancelamento de Clientes

> Projeto de estudo realizado durante o \*\*Python Insights da Hashtag Treinamentos\*\*.

## &#x20;Sobre o projeto

Este projeto apresenta uma análise exploratória de uma base de clientes com o objetivo de entender o comportamento de cancelamento e identificar padrões que podem estar relacionados ao **churn**.

A análise parte da preparação dos dados e evolui para a exploração das principais características dos clientes, buscando transformar os dados em informações úteis para tomada de decisão.

## &#x20;Tecnologias utilizadas

* **Python**
* **Pandas** — tratamento, transformação e análise dos dados
* **Plotly** — visualização dos resultados
* **Jupyter Notebook** — desenvolvimento e documentação da análise

## &#x20;Etapas da análise

```text
Base de clientes
      ↓
Exploração dos dados
      ↓
Tratamento e preparação
      ↓
Análise de cancelamentos
      ↓
Segmentação dos clientes
      ↓
Identificação de padrões
      ↓
Insights para o negócio
```

## &#x20;Principais análises

O projeto investiga questões como:

* Qual é a proporção de clientes que cancelaram?
* Quais características aparecem associadas ao cancelamento?
* Existe relação entre tipo de contrato e churn?
* O volume de ligações ao call center apresenta relação com cancelamento?
* Atrasos de pagamento aparecem relacionados ao churn?
* Quais segmentos apresentam maior concentração de cancelamentos?
